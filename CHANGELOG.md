# Changelog

## 1.0.0 — 2026-09-23
- First release for Minecraft Java 26.2 and 26.3. Needs Timber 1.1.0 or newer.
- New axe enchantment, Timber (max level I). Only axes with it fell whole trees; others chop one log.
- Obtainable like Efficiency: enchanting table (rare, like Fortune), librarian books, chest loot and fishing, and enchanted villager axes. Anvils combine it as usual. It can't go on other tools.
- Timber's join hint and settings menu say that the enchantment is needed.
- A chat warning, with a download link, if Timber is missing or older than 1.1.0, or if the pack was added with `/reload` instead of a restart.
- `/function enchanted_timber:uninstall` removes the add-on's data.
